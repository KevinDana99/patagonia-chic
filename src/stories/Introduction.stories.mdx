# Bienvenidx a nuestra librería de componentes 🎉

Aquí encontrarás todos los elementos reutilizables que podrás incoporar en el proyecto. Cuentas con:
- Los componentes de React, pudiendo ver en acción su interacción dependiendo de las props y la manera en la que se comportan sus actions.
- Ilustraciones.
- Reglas de uso de elementos de diseño.

La creación de esta documentación se ha hecho de la mano de Storybook, y por cada componente nuevo que añadas aquí deberás incorporar un archivo de Storybook con diferentes reglas para que pueda visualizarse aquí. Pero no te preocupes! Es sencillo.

Para utilizar esta librería simplemente instála en tu proyecto con el siguiente comando:

```bash
yarn add patagoniachic-react-ui
```
